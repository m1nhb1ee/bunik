📐 Chuẩn hóa 2NF — Phân tích

2NF yêu cầu: đã đạt 1NF + không có phụ thuộc hàm bộ phận (partial dependency). Mọi thuộc tính non-key phải phụ thuộc vào toàn bộ khóa chính.

🔴 Vi phạm 2NF chính: Bảng MAJORS hiện tại

Bảng MAJORS hiện có composite key logic (university_id, code). Nhưng major_name chỉ phụ thuộc vào code (mã ngành), KHÔNG phụ thuộc university_id.
VD: Mã 7480201 luôn là "Công nghệ thông tin" dù ở trường nào → Partial dependency!

❌ Trước — Vi phạm 2NF

-- major_name phụ thuộc code, KHÔNG phụ thuộc university_id MAJORS ├── id (PK) ├── university_id (FK) ─┐ ├── code: "7480201" ─┤→ composite key logic ├── name: "CNTT" ← chỉ phụ thuộc code! └── description ← chỉ phụ thuộc code! -- Data lặp lại 88 lần cho 88 trường cùng mở ngành CNTT -- → Redundancy + Update anomaly
→

✅ Sau — 2NF Compliant

MAJOR_CATALOG -- Danh mục ngành quốc gia ├── id (PK) ├── code: "7480201" (UNIQUE) ├── name: "Công nghệ thông tin" ├── field_id (FK → FIELDS) └── description -- Mỗi mã ngành CHỈ xuất hiện 1 lần UNIVERSITY_MAJORS -- Trường mở ngành nào ├── id (PK) ├── university_id (FK) └── major_catalog_id (FK) -- Junction: university ←→ major (N:N)

🟡 Cải tiến kiến trúc: Thêm FIELDS (Lĩnh vực/Nhóm ngành)

Để filter/sort theo lĩnh vực (Kỹ thuật, Y Dược, Kinh tế...), cần bảng FIELDS nhóm các ngành lại. Đây cũng là chuẩn 2NF — tách nhóm ngành ra khỏi bảng ngành vì nó là thuộc tính của "lĩnh vực", không phải của "ngành học".

FIELDS -- Lĩnh vực đào tạo ├── id: 1 ├── name: "Công nghệ thông tin" └── code: "748" └── MAJOR_CATALOG (field_id = 1) ├── 7480101 — An toàn thông tin ├── 7480201 — Công nghệ thông tin └── 7480103 — Kỹ thuật phần mềm

👁️ Views — Tối ưu Query

Materialized views flatten các JOIN phức tạp, phục vụ API/Frontend filter nhanh.

📊 View 1: v_admission_overview — Bảng tổng hợp điểm chuẩn

Flatten toàn bộ — 1 query trả về đủ thông tin cho danh sách filter/sort.

CREATE MATERIALIZED VIEW v_admission_overview AS SELECT -- University u.id AS university_id, u.name AS university_name, u.short_name, u.type AS university_type, p.name AS province, p.region, -- Major mc.id AS major_catalog_id, mc.code AS major_code, mc.name AS major_name, f.name AS field_name, -- Score s.year, s.score, s.quota, am.name AS admission_method, s.note FROM admission_scores s JOIN university_majors um ON um.id = s.university_major_id JOIN universities u ON u.id = um.university_id JOIN provinces p ON p.id = u.province_id JOIN major_catalog mc ON mc.id = um.major_catalog_id LEFT JOIN fields f ON f.id = mc.field_id JOIN admission_methods am ON am.id = s.admission_method_id; -- Index cho view CREATE UNIQUE INDEX ON v_admission_overview (university_id, major_catalog_id, year, admission_method); CREATE INDEX ON v_admission_overview (year DESC, score DESC); CREATE INDEX ON v_admission_overview (province, university_type); CREATE INDEX ON v_admission_overview (field_name);

📈 View 2: v_university_stats — Thống kê trường

CREATE MATERIALIZED VIEW v_university_stats AS SELECT u.id, u.name, u.short_name, u.type, p.name AS province, p.region, COUNT(DISTINCT um.major_catalog_id) AS total_majors, ROUND(AVG(s.score), 2) AS avg_score, MIN(s.score) AS min_score, MAX(s.score) AS max_score FROM universities u JOIN provinces p ON p.id = u.province_id LEFT JOIN university_majors um ON um.university_id = u.id LEFT JOIN admission_scores s ON s.university_major_id = um.id AND s.year = (SELECT MAX(year) FROM admission_scores) GROUP BY u.id, u.name, u.short_name, u.type, p.name, p.region;

🔎 Query Examples — Filter & Sort

Ví dụ các truy vấn phổ biến sử dụng schema mới — tất cả đều nhanh nhờ indexes + views.

🏫 Filter trường theo khu vực + loại

Tìm trường công lập ở Hà Nội, sort theo điểm TB
SELECT * FROM v_university_stats WHERE province = 'Hà Nội' AND type = 'công_lập' ORDER BY avg_score DESC;

📚 Filter ngành theo lĩnh vực

Tìm điểm CNTT năm 2025, sort theo điểm chuẩn
SELECT university_name, major_name, score, admission_method FROM v_admission_overview WHERE field_name = 'CNTT' AND year = 2025 ORDER BY score DESC;

📊 Xu hướng điểm chuẩn qua các năm

Điểm ngành CNTT ở Bách Khoa 2021-2025
SELECT year, score FROM v_admission_overview WHERE short_name = 'BKA' AND major_code = '7480201' ORDER BY year;

🎯 Tìm ngành phù hợp với điểm

Ngành nào lấy 25.0 điểm trở xuống, năm 2025
SELECT university_name, major_name, score, province FROM v_admission_overview WHERE year = 2025 AND score <= 25.0 ORDER BY score DESC LIMIT 50;

🏆 Top trường theo khu vực

Top 10 trường miền Bắc, điểm TB cao nhất
SELECT name, avg_score, total_majors FROM v_university_stats WHERE region = 'Bắc' ORDER BY avg_score DESC LIMIT 10;

📋 Tổ hợp môn cho ngành cụ thể

Tổ hợp nào xét cho ngành 7480201?
SELECT sg.code, sg.subjects FROM major_subject_groups msg JOIN subject_groups sg ON sg.id = msg.subject_group_id JOIN major_catalog mc ON mc.id = msg.major_catalog_id WHERE mc.code = '7480201';
